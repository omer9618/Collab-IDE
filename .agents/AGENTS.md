# Custom Rules

- ALWAYS create a new git branch before making any code changes. NEVER push directly to the `main` branch.

- **Proactive Optimization & Regression Prevention:** When verifying if a requirement is already implemented, do not stop at surface-level compliance. Actively analyze the implementation to ensure it is designed in the optimal, most resilient way (addressing edge cases, performance bottlenecks, and scale). If proposing or making "superior" improvements, you MUST guarantee that the changes are isolated and do not disrupt any existing functionality or other established requirements.
